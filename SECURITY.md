# Security Policy

## Supported Versions

Only the latest published release of Yamaha PortaSound Studio is actively maintained with security and stability updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.6.x   | :white_check_mark: |
| < 2.6.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it responsibly:
- **Do not open a public issue** disclosing the vulnerability details.
- Please report security concerns through [GitHub Private Vulnerability Reporting](https://github.com/Gouldin84/Yamaha-PortaSound-Studio/security/advisories/new).
- Provide detailed steps to reproduce the issue along with any relevant technical logs.

Reports will be reviewed promptly, and fixes will be coordinated through a patch release.
